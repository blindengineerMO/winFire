# API route reference

Generated by `npm run docs:api` from the registered Express routes and OpenAPI schemas. Do not edit this file by hand. Regeneration uses a temporary SQLite database; it does not start schedulers or connect to inventory hosts.

All paths below are relative to `/api/v1`. See [API usage and curl examples](API.md) for authentication, query conventions, workflows, and errors. Source links point to the handler with its complete validation and resource authorization checks.

`bearerAuth` = operator access token; `mutualTLS` = enrolled agent certificate; `internetDeviceBearer` = browser device token; `wefHmac` = node-scoped WEF token. “No bearer” routes can still require credentials, an enrollment token, HTTPS, or prompt-specific authorization. Permission gates are additive to per-resource grants and ownership checks.

Some older operations publish a generic JSON body. For those, follow the linked handler; an unspecified schema does not mean that arbitrary input is accepted. Response codes in the live OpenAPI spec remain generic for some older endpoints.
